# DEAD MEMORY — เคส 1: ความทรงจำที่หายไป

เพิ่มระบบปริศนาในโปรเจกต์ Unity `C:/Users/nuene/Esan` ฉาก `Assets/Scenes/SampleScene.unity`

## วิธีเริ่ม

เปิดฉาก SampleScene แล้วกด Play เลือก **เริ่มความทรงจำใหม่** หรือ **เล่นต่อจากบันทึก**

- WASD: เดิน / เมาส์: มอง
- Shift: วิ่ง
- Q: วนระหว่างไฟขาว → ไฟฉาย UV → เก็บไฟฉาย
- E: ตรวจสิ่งของ อ่านโน้ต เก็บของ หรือใช้อุปกรณ์
- Tab: สมุดบันทึก คำใบ้ที่ค้นพบ และไอเท็ม
- Esc: ปิดหน้าต่างปริศนา
- หน้ากุญแจรหัส: คลิกตัวเลข หรือใช้แป้นตัวเลข/แป้นตัวเลขด้านข้าง และ Enter

ระบบบันทึกความคืบหน้าเมื่อสำรวจ เก็บของ และแก้ปริศนา เลือกเริ่มใหม่เพื่อล้างบันทึกเฉพาะเคสนี้ ไม่มีการล้างการตั้งค่าอื่นของเกม

## โครงสร้างด่าน

| ห้อง | หน้าที่ |
|---|---|
| 101 | จุดเริ่ม บันทึกแรก ตารางเรียน รอย UV และตู้รูปถ่าย |
| 102 | กล่องเครื่องมือล็อกรหัส และใบแจ้งซ่อม |
| 103 | กุญแจลิ้นชักครู และฟิวส์หลังตะแกรงที่ต้องใช้ไขควง |
| 104 | ฟิวส์สีน้ำเงิน และรอย UV เกี่ยวกับเลขที่ของตัวเอก |
| 105 | แฟ้มครู เข็มนาที และผังสวิตช์ที่ต้องส่อง UV |
| 106 | ฟิวส์สีเขียว และตู้ติดแน่นที่ต้องใช้ชะแลง |
| 107 | แผงใส่ฟิวส์และปริศนาลำดับสวิตช์ |
| 108 | นาฬิกาขาดเข็มและช่องลับที่ซ่อนกุญแจตู้รูปถ่าย |

ออกแบบจังหวะให้ผู้เล่นใหม่ใช้เวลาประมาณ **18–25 นาที** โดยไม่บังคับให้รอ เวลาเล่นจริงขึ้นกับการอ่าน การสำรวจ และความคุ้นเคยกับปริศนา ต้องทดสอบกับผู้เล่นที่ยังไม่รู้คำตอบเพื่อยืนยันระยะเวลา 20 นาที การทดสอบอัตโนมัติที่รู้คำตอบไม่ใช่การวัดเวลาเล่นครั้งแรก

## หลักการทำงาน

รอย UV ต้องอยู่ในระยะและลำแสงสีม่วง ผนังหรือวัตถุทึบสามารถบังได้ ไฟขาวไม่เปิดเผยรอย เมื่อพบหลักฐานแล้วสามารถทบทวนในสมุดบันทึกได้

การเดารหัสผิดไม่ทำให้กุญแจหาย การเปิดสวิตช์ผิดไม่ทำลายฟิวส์ สามารถใส่ฟิวส์หรือเข็มนาฬิกาทีละส่วนแล้วกลับมาทำต่อได้

แต่ละกลไกมีข้อความบอกเมื่อยังขาดอุปกรณ์ สมุดบันทึกมีปุ่มขอคำใบ้ตามความคืบหน้า

ตอนจบของเคสนี้คือการเปิดตู้และตรวจรูปถ่าย ก่อนขึ้นหน้าจอจบความทรงจำ ยังไม่มีการสร้างฉาก Chapter 2

## เฉลยสำหรับผู้พัฒนา

1. อ่านตารางเรียน 08:00 / 12:00 / 15:00 และส่อง UV ที่กระดานห้อง 101 รอยบอกให้ใช้หลักหน่วยของชั่วโมง จึงได้ **825**
2. เปิดกล่องห้อง 102 รับไขควง ใช้เปิดตะแกรงห้อง 103 รับฟิวส์สีแดง
3. เก็บฟิวส์สีน้ำเงินห้อง 104 และสีเขียวห้อง 106
4. ส่อง UV ที่ผังห้อง 105 แล้วใส่ฟิวส์ที่แผงห้อง 107 กด **ซ้าย → ขวา → กลาง** รับชะแลง
5. ใช้ชะแลงงัดตู้ห้อง 106 รับเข็มชั่วโมง เก็บกุญแจห้อง 103 แล้วเปิดแฟ้มครูห้อง 105 รับเข็มนาที
6. รอย UV ห้อง 104 บอกเลขตัวเอก **03** แฟ้มครูบอกเลขเพื่อน **15** และวิธีแปลเป็นเวลา
7. ใส่เข็มทั้งสองที่นาฬิกาห้อง 108 ตั้งเป็น **03:15** รับกุญแจตู้รูปถ่าย
8. กลับห้อง 101 เปิดตู้ด้วยกุญแจและรหัส **0315** แล้วกด E ตรวจรูปถ่ายเพื่อจบเคส
