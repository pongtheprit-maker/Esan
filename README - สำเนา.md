# DEAD MEMORY

> **กฎของไฟล์นี้:** อัปเดตทุกครั้งที่ทำงานเสร็จ (ความคืบหน้า / คอนเซ็ปต์ / เนื้อเรื่อง / ปริศนา)
> ข้อมูลที่ยังไม่ได้ตัดสินใจจะเขียนว่า **ยังไม่กำหนด** ห้ามเดาเอง

อัปเดตล่าสุด: 14 ต.ค. 2026

---

## 1. คอนเซ็ปต์เกม

- ชื่อเกม: **DEAD MEMORY**
- แนว: สยองขวัญเอาชีวิตรอด มุมมองบุคคลที่หนึ่ง บรรยากาศกดดัน คาดเดายาก แบบ Outlast
- แกนเกม: สำรวจ แก้ปริศนา อยู่รอด ผู้เล่นเป็นนักสืบที่ต้องเข้าไปในความทรงจำ
- ตอนนี้ทำอยู่: **เคส 1** (ฉากโรงเรียนมัธยม)

## 2. เนื้อเรื่อง

### ตัวละครและเหตุการณ์หลัก (ยืนยันแล้ว)
- ตัวเอกเป็นนักสืบ
- เพื่อนเป็นเพื่อนสมัยเด็ก และเป็นนักสืบด้วยกันเมื่อโตขึ้น
- เพื่อน **เสียชีวิตตอนโตเต็มวัย เพราะปกป้องตัวเอก**
- เรื่องการตายนี้เป็นความทรงจำที่จะ **เล่าในช่วงเนื้อเรื่องที่ 2** (ไม่ใช่เคส 1)

### เคส 1 (ข้อมูลที่กำหนดแล้ว)
- ฉากคือความทรงจำในวัยเด็กของนักสืบ
- โรงเรียนมัธยมช่วงเย็นหลังเลิกเรียน ถูกทิ้งร้าง
- ตัวเอกอยู่ในห้องเรียนคนเดียว
- ตู้เหล็กเป็นจุดเปลี่ยนไปยังสถานที่ถัดไป

### แนวทางที่เสนอ (รอยืนยัน)
เพราะการตายของเพื่อนถูกเก็บไว้เล่าช่วงที่ 2 เคส 1 ควร **ไม่เฉลยเรื่องการตาย** ปูได้แค่เบา ๆ เช่น คำสัญญาสมัยเด็กว่าจะเป็นนักสืบด้วยกัน ความทรงจำอบอุ่นแต่มีบางส่วนถูกลบ/ผิดเพี้ยน

### ยังไม่กำหนด
- ชื่อตัวเอก ชื่อเพื่อน
- ความหมายของแสงประหลาด
- เคส 1 ปูเรื่องการตายของเพื่อนแค่ไหน
- สถานที่ถัดไป และเนื้อเรื่องหลังเคส 1

## 3. ปริศนาเคส 1

**ตัดสินใจแล้ว: ใช้แบบ C (ผสม)**
รหัสตู้เหล็ก 4 หลัก = **ชั่วโมงจากนาฬิกา (2 หลัก) + เลขที่นั่งของเพื่อน (2 หลัก)**
ค่าตัวอย่างที่เสนอ (**รอยืนยัน**): 16 + 07 = **1607**

ลำดับที่ผู้เล่นควรพบ: กระดานดำ → โต๊ะที่มีรอยสลัก → นาฬิกา → สมุดเช็กชื่อ → ตู้เหล็ก → กรอบรูปในตู้

| จุดคำใบ้ | แสงปกติ | แสงม่วง UV | หน้าที่ในปริศนา |
|---|---|---|---|
| กระดานดำ | ตารางคาบ คาบสุดท้ายถูกลบบางส่วน | ข้อความมือเขียน **ลายมือเด็กแต่เนื้อหาเหมือนคนโตเขียน** ชวนให้รู้สึกว่าความทรงจำไม่ปกติ (ไม่ใช่ตัวเลข ไม่เฉลยการตาย) | ตั้งต้นเรื่อง และยืนยันว่าเป็นช่วงเย็น (ใช้ตีความเลข 4 เป็น 16) |
| โต๊ะมีรอยสลัก | ชื่อตัวเอกกับเพื่อน | เลขที่นั่งของเพื่อน (ตัวอย่าง 07) | ให้หลักที่ 3-4 |
| นาฬิกาผนัง | เก่า ชำรุด เหลือเข็มชั่วโมงเดียว ชี้เลข 4 | รอยเข็มนาทีเดิมบนหน้าปัด | ให้หลักที่ 1-2 (อ่านเป็น 16) |
| สมุดเช็กชื่อ | บนโต๊ะครู เพื่อนเซ็นชื่อวันนั้น | - | ยืนยันเลขที่นั่งเพื่อน |
| ตู้เหล็ก | รหัส 4 หลัก | - | เปิดแล้วเจอกรอบรูป |
| กรอบรูปในตู้ | ภาพเก่าตัวเอกกับเพื่อน | ด้านหลังมีชื่อสถานที่ถัดไป | จุดเปลี่ยนไปสถานที่ถัดไป |

กติกา: แสงประหลาดนำสายตาผู้เล่นไปทางโต๊ะครู / สมุดเช็กชื่อได้ แต่ **ห้ามเฉลยคำตอบตรง ๆ และไม่ชี้ไปที่ตัวเลข**

### ยังไม่กำหนด
- ยืนยันค่าตัวเลขจริง (16 และ 07 เป็นเพียงตัวอย่าง)
- ตำแหน่งตู้เหล็กเป้าหมายและเส้นทางเข้าถึงจากในโรงเรียน
- ชื่อสถานที่ถัดไปที่เขียนหลังกรอบรูป
- ตำแหน่งและหน้าตาของแสงประหลาด

### แนวข้อความบนกระดานดำ (ตัดสินแล้ว)
ลายมือเด็ก แต่เนื้อหาฟังเหมือนคนโตเขียน ชวนให้รู้สึกว่าความทรงจำไม่ปกติ เหมาะกับแนวสยองขวัญ ไม่มีตัวเลข ไม่เฉลยเรื่องการตาย

**ประโยคที่เลือก (ตัดสินแล้ว):** ครั้งหน้าเป็นฉันที่ต้องไปก่อน
ความหมาย: ปูเรื่องการตายของเพื่อนในช่วงที่ 2 แบบไม่เฉลย ผู้เล่นรู้สึกแปลก ๆ แต่ยังไม่รู้ว่าหมายถึงอะไร

ประโยคที่ไม่ได้ใช้ (เก็บไว้ใช้ภายหลังได้): นายจำได้ไหมว่าฉันอยู่ตรงนั้น / อย่าเปิดตู้ ถ้ายังไม่พร้อมจำ / ฉันไม่เคยออกไปจากห้องนี้เลยนะ

### ค่าเริ่มต้นที่ใช้ไปก่อน (ผู้ใช้ยังไม่ได้ตอบ ปรับได้ทุกเมื่อ)
- รหัสตู้ = **1607**
- ตู้เหล็กเป้าหมายอยู่ที่ **ทางเดินหน้าห้องเรียน** (เข้ากับตู้ล็อกเกอร์ที่มีในฉากแล้ว)

### คำถามที่รอคำตอบ
1. ยืนยันรหัส 1607 และตำแหน่งตู้ที่ทางเดินหน้าห้อง
2. ฟอนต์/ลายมือสำหรับรอย UV: ต้องมีฟอนต์ที่รองรับภาษาไทย หรือรูปลายมือที่ทำไว้แล้ว (Unity AI Generators ใช้ไม่ได้ เพราะ NoSubscription)

## 4. ระบบในเกม

| ระบบ | สคริปต์ | สถานะ |
|---|---|---|
| ผู้เล่นมุมมองบุคคลที่หนึ่ง | `FirstPersonController` | มีอยู่เดิม |
| แสตมินา / หายใจ / สายตาล้า | `StaminaSystem`, `BreathingAudio`, `FatigueVision` | มีอยู่เดิม |
| ความมีสติ (Sanity) | `SanitySystem`, `SanityHUD`, `SanityHeartbeatGraphic`, `SanityPerceptionTarget`, `SanityThreat` | มีอยู่เดิม |
| ประตู | `SchoolDoor`, `PlayerDoorInteractor` | มีอยู่เดิม |
| ไฟกะพริบ | `FlickerLight` | มีอยู่เดิม |
| **ไฟฉาย 2 โหมด (ปกติ / ม่วง UV)** | `FlashlightController` | **ทำแล้ว** ทดสอบการตอบสนองของแสงและการเผยรอยแล้ว |
| **รอยที่เห็นเฉพาะแสงม่วง** | `UVRevealable` + เมนู `GameObject > UV Light > Create UV Mark (Quad)` | **ทำแล้ว** (ยังไม่ได้วางรอยจริงในฉาก) |
| ระบบรหัสตู้ 4 หลัก | - | ยังไม่ได้ทำ (ดีไซน์ตัดสินแล้ว แบบ C รอยืนยันค่าตัวเลข) |
| ลำดับคำใบ้ / การติดตามความคืบหน้าปริศนา | - | ยังไม่ได้ทำ (`UVRevealable.Revealed` event เตรียมไว้ให้เชื่อมได้) |

### วิธีใช้ไฟฉาย
- กด **Q** วนเป็น: ลดไฟฉาย → แสงปกติ → **แสงม่วง UV** → ลดไฟฉาย
- ปรับค่าได้ที่ `FlashlightController` ใน Inspector: `uvColor`, `uvIntensity`, `uvRange`, `uvSpotAngle`, `uvInnerSpotAngle`, `cycleThroughOff` (ปิดเพื่อให้ Q สลับแค่ปกติ ↔ ม่วง)
- วางรอย UV: คลิกขวาใน Hierarchy → UV Light → Create UV Mark (Quad) แล้ววางห่างผิวกระดาน/โต๊ะ/ผนัง 1–2 ซม. ใส่ `Mark Texture` เป็นลายมือหรือรอยสลัก ตั้ง `clueId` เช่น blackboard_date

## 5. ความคืบหน้าฉากโรงเรียน

**สถานะที่ตรวจเห็นจริงในฉาก (SampleScene)**: มีอาคาร School / WestBuilding, โต๊ะ เก้าอี้ ตู้ล็อกเกอร์ กระดานดำ (เช่น Blackboard (6)) หลอดไฟเพดาน (Tube) หน้าต่าง ไฟกะพริบ และผู้เล่น

**ยังไม่ได้ตรวจรายการตามบรีฟ** ว่าครบหรือยัง:
- [ ] โต๊ะครู สมุดเช็กชื่อ ชอล์ก แปรงลบ โปสเตอร์
- [ ] โต๊ะที่มีรอยสลักความทรงจำ
- [ ] นาฬิกาผนังชำรุด
- [ ] ป้ายห้อง กระดานประกาศ ม้านั่ง ถังขยะในทางเดิน
- [ ] ห้องน้ำ (สุขภัณฑ์ กระจก ที่กั้นคอก)
- [ ] ตู้เหล็กเป้าหมายและกรอบรูปภายใน
- [ ] แสงประหลาดนำสายตา
- [ ] ตรวจวัตถุลอย / จมพื้น / ทะลุผนัง / ขวางประตู จากมุมมองบุคคลที่หนึ่ง

ขอบเขต: ห้ามเพิ่มระบบต่อสู้ เนื้อเรื่องใหม่ ศัตรูใหม่ ยังไม่ต้องสร้างชั้น 2 หรือบันไดลง

## 6. หมายเหตุทางเทคนิค
- Unity ใช้ URP, Input System ใหม่
- Console เตือน shadow atlas 2048x2048 ไม่พอ (มีไฟทำเงาพร้อมกันมากถึง 42 ดวง) ควรจำกัดจำนวนไฟที่เปิดเงา หรือเพิ่มขนาด atlas
- Console มี error `NoSubscription` จาก Unity AI Generators ใช้สร้างภาพ/เสียง/โมเดลด้วย AI ผ่าน Unity ไม่ได้
- ตอนทดสอบผ่าน MCP ถ้า Unity ไม่ได้ focus เกมจะไม่เดินเฟรมและไม่รับปุ่มคีย์บอร์ดจำลอง
